# 答案与安全边界

## 保护目标

项目尽量避免把当前回合答案直接发送给浏览器，并防止浏览器自行决定多人胜负。题库作品列表本身是公开数据，
不属于秘密；保护重点是当前答案、重连凭据和进行中的其他玩家操作。

## 服务端判定

- 单人 API 保存当前答案，只返回当前阶段允许公开的线索。
- 多人服务保存房间答案、计时、已提交状态和胜负结果。
- 浏览器提交稳定作品标识，服务端使用对应房间的题库重新查找和校验。
- 回合凭据和多人重连凭据使用随机值，并设置生命周期和重复使用限制。

## 浏览器边界

浏览器中的搜索索引不是判定依据。本机战绩可以被用户修改，因此仅作为个人记录展示，不用于排行榜、匹配或
服务端奖励。

## 资源限制

多人服务限制连接数、同 IP 连接数、房间总数、同 IP 房间和席位数量，并对创建、加入和猜测操作设置速率
限制。房间只保存在内存中，并通过空闲与绝对生命周期自动清理。

## 不在范围内

开源项目无法阻止用户阅读完整题库、修改自己的浏览器界面或伪造本机战绩。项目也不承诺抵御拥有服务器
控制权的部署者。

发现答案泄露、越权操作、重连凭据问题或可导致服务不可用的缺陷时，请按照
[SECURITY.md](../SECURITY.md) 私密报告。
