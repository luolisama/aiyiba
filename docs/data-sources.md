# 数据来源与收录规则

## 题库范围

- 标准题库：70 首，主要来自 ilem 的 Bilibili 主账号音乐投稿。
- 扩展题库：81 首，包含标准题库，并补充 ilem/onyk 作为 staff 参与的原创作品和被删除作品。
- 扩展题库不包含翻唱与 Remix。

## 来源优先级

1. [ilem 的 Bilibili 投稿页](https://space.bilibili.com/3379951/upload/video)：投稿范围、标题、BV 号和封面。
2. Bilibili 公开页面或接口快照：投稿时间和播放量。
3. VCPedia、萌娘百科等资料页：作品关系、演唱者和引擎的交叉参考。
4. 作者说明、历史页面快照和人工确认：处理删稿、staff 作品和标题未注明歌姬等情况。

投稿日期、BV 号和当前可访问作品的播放量优先以 Bilibili 为准。演唱、引擎和收录决定允许人工校正，但校正
应在对应的纠错 Issue 或 Pull Request 中保留可复核来源，或明确注明推断；当前公开 JSON 只包含游戏所需字段，
不携带逐条来源和审核状态。

## 字段说明

- name：网页使用的作品名，不保留投稿标题中的宣传性前后缀。
- singer：实际演唱者；纯音乐为“无”。
- engine：演唱合成引擎；真人或纯音乐为“无”。
- date：Bilibili 投稿日期。
- views：定期更新的播放量快照。
- tier：根据播放量快照计算的普通、殿堂、专兑、传说或神话。
- searchAliases：繁简体、常见别名和历史标题等搜索兼容项。

## 纠错

题库纠错请使用仓库 Issue 表单，并提供作品、字段、建议值和来源。无法人工取得可靠信息，或不符合原创收录
口径的作品不会仅凭推测加入题库。
